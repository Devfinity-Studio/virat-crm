# Virat CRM

Virat CRM is a comprehensive Customer Relationship Management and Enterprise Resource Planning (ERP) application built for the modern workforce. It features an advanced hierarchy system, field support reporting, daily mileage tracking, inventory management, and extensive sales pipelines.

## Key Features
- **User Hierarchy**: Manage employees across multiple organizational levels with reporting managers and dynamic branch assignments.
- **Inventory & Sales**: Full inventory tracking with stock transfers, sales assignments, and replacements.
- **Field Support & Tracking**: Daily reports, location logs, customer visits, and breadcrumb tracking.
- **Advanced Permissions**: Granular role-based access control and system settings management.
- **Push Notifications**: Web-push and email alerts via Resend for real-time updates.

## Tech Stack
- **Frontend**: Next.js (App Router), React, Tailwind CSS, shadcn/ui
- **Backend**: TRPC, Drizzle ORM, PostgreSQL
- **Deployment**: Vercel ready

For more information on setup and architecture, refer to the other documentation files in this repository.
