# Technology Stack

**Analysis Date:** 2026-10-31

## Languages

**Primary:**
- TypeScript 5.8.2 - All application source code (`strict: true`, target ESNext, NodeNext/Bundler module resolution, full typing for tRPC routers, Drizzle models, React components, and domain services)

**Secondary:**
- JavaScript (Node.js/ESM) - Build scripts and root tooling (`next.config.js`, `eslint.config.js`, `postcss.config.js`, `prettier.config.js`, `scripts/sync_db.js`)
- SQL - PostgreSQL schema migrations generated by Drizzle Kit in `drizzle/`
- Java / Kotlin / Swift - Native platform wrapper code generated in `android/` and `ios/`

## Runtime

**Environment:**
- Node.js 20.x+ (LTS) - Server runtime for Next.js App Router and API routes
- React 19.0.0 - Frontend rendering engine (Client and Server Components)
- Native Mobile Shell: Capacitor 8.4.2 (`@capacitor/core`, `@capacitor/cli`, `@capacitor/android` 8.4.2, `@capacitor/ios` 8.5.2) wrapping the responsive Next.js application inside native WebViews

**Package Manager:**
- `pnpm` 11.3.0
- Lockfile: `pnpm-lock.yaml` present and maintained
- Workspace config: `pnpm-workspace.yaml` present

## Frameworks

**Core:**
- Next.js 15.2.3 - Full-stack React framework utilizing the App Router architecture (`src/app`), Server Components, and Edge Middleware
- tRPC v11 (`@trpc/server`, `@trpc/client`, `@trpc/react-query`) - End-to-end type-safe RPC API with procedure-level middlewares
- TanStack Query v5 (`@tanstack/react-query` 5.69.0) - Asynchronous state management, client caching, and cache invalidation
- REST Compatibility: `trpc-to-openapi` (3.2.0) - OpenAPI v3 documentation and REST-compatible endpoints (`src/app/api/rest`)

**UI & Styling:**
- Tailwind CSS v4 (`tailwindcss` 4.0.15, `@tailwindcss/postcss` 4.0.15) - Utility-first styling framework
- `shadcn/ui` & Radix UI primitives (`@radix-ui/*`) - Headless accessible UI component library (`src/components/ui/`)
- `class-variance-authority` (0.7.1), `clsx` (2.1.1), `tailwind-merge` (3.5.0) - Dynamic class composition via `cn()` helper
- `lucide-react` (1.12.0) - Icon system across desktop and mobile layouts
- `framer-motion` (12.38.0) - Smooth animations and UI transitions
- `vaul` (1.1.2) - Mobile drawer sheets and bottom dialogs

**Testing:**
- Vitest 4.1.7 (`vitest`) - Fast Vite-native unit and integration test runner
- `vite-tsconfig-paths` (6.1.1) - TypeScript path mapping support during test execution

**Build & Tooling:**
- Turbopack (`next dev --turbo`) - Development build bundler
- TypeScript Compiler (`tsc --noEmit`) - Strict static type validation
- ESLint 9 (`eslint` 9.23.0, `eslint-config-next` 15.2.3, `eslint-plugin-drizzle` 0.2.3) - Flat configuration linting in `eslint.config.js`
- Prettier 3.5.3 (`prettier-plugin-tailwindcss` 0.6.11) - Code and class formatting

## Configuration

**Environment:**
- Defined and runtime-validated via `src/env.js` using `@t3-oss/env-nextjs` and `zod`
- Sourced from local `.env` file (template provided in `.env.example`)
- Key required server variables: `DATABASE_URL`, `AUTH_SECRET`, `R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_BUCKET_NAME`, `VAPID_PRIVATE_KEY`
- Key required client variables: `NEXT_PUBLIC_VAPID_PUBLIC_KEY`, `NEXT_PUBLIC_PINCODE_API_URL`, `NEXT_PUBLIC_GEOCODING_API_URL`, `NEXT_PUBLIC_MAP_TILE_URL`

**Build:**
- `tsconfig.json` - TypeScript compiler flags (`strict: true`, target ESNext, moduleResolution Bundler)
- `next.config.js` - Next.js configuration and image domains
- `drizzle.config.ts` - Drizzle Kit schema and database connection definitions
- `capacitor.config.ts` - Native app ID (`com.devfinity.viratcrm`), app name, and web server bridge target

## Platform Requirements

**Development:**
- Node.js 20+ on Windows, macOS, or Linux
- Package manager: `pnpm` 11+
- Local PostgreSQL instance or remote Neon Serverless PostgreSQL instance
- Android Studio / Xcode (optional, required only for native mobile builds)

**Production:**
- Web App: Deployed on Vercel or Node.js server container
- Mobile App: Distributed via Google Play Store (`android/`) and Apple App Store (`ios/`) with production URL pointing to `https://virat-crm.vercel.app`
- Database: Managed PostgreSQL (Neon / AWS RDS / Supabase)
- Object Storage: Cloudflare R2 or AWS S3
