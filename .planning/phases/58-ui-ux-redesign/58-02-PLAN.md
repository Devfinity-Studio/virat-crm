# Phase 58 — Plan 02: Mobile Navigation, Status Hero & Plain-Language Workflows

## Goal
Implement the mobile-first navigation shell and plain-language user experience designed for non-technical field employees: fixed bottom navigation bar, giant status indicator, offline countdown banner, location permission guide, and simplified login flow.

---

## Tasks

### Task 1: Role-Aware Bottom Navigation Shell (`UI-NAV-01`, `UI-MOBILE-01`)
- **Target Files:**
  - `src/app/_components/layout/BottomNav.tsx` (new)
  - `src/app/_components/layout/DashboardLayout.tsx`
- **Actions:**
  - Build fixed bottom navigation bar:
    - Minimum height `56px` + safe-area inset (`pb-safe`).
    - Touch targets minimum `52px` wide/tall.
    - Large icon AND readable label on every item (never icon-only).
  - Strict RBAC sanitization:
    - **Employee items (max 3-4):** Home / Today, Activity / Attendance, Profile & Help.
    - **Admin items (max 3-4):** Live Map, Employees, Alerts / Activity, Manage.
    - Employee clients never receive or render Admin links or controls.
  - Ban hamburger menus on mobile viewport; make all primary destinations directly accessible.

### Task 2: Plain Language Status Dashboard & Geolocation Indicators (`UI-STATUS-01`)
- **Target Files:**
  - `src/app/_components/dashboard/StatusHeroCard.tsx` (new)
  - `src/app/_components/dashboard/OfflineCountdownBanner.tsx` (new)
  - `src/app/page.tsx`
- **Actions:**
  - Replace technical jargon with plain language:
    - "Your Location is Sharing Normally" (Green checkmark card, employee name, duty status).
    - "Today's Work Summary" (Logged in at 9:00 AM, last update 2 mins ago).
  - Build `<OfflineCountdownBanner />` directly wired to the 22-minute offline buffer:
    - High-visibility amber banner: "No Internet: Your work is safe. Please turn on mobile data within X minutes."
  - Build quick-action cards for field tasks (Attendance, Daily Report, New Sale).

### Task 3: Permission Onboarding & Lockout Overhaul (`UI-STATUS-01`, `UI-MOBILE-01`)
- **Target Files:**
  - `src/app/_components/auth/PermissionOnboardingFlow.tsx` (new)
  - `src/app/login/page.tsx`
- **Actions:**
  - Implement 1-2-3 visual guide for Android APK background location permissions:
    - Step 1: Tap "Turn On Location Now"
    - Step 2: Select "Allow all the time" on the Android prompt
    - Step 3: Green confirmation "You are all set!"
  - Redesign Lockout screen with high-contrast crimson banner and single action: "Fix & Log Back In".
  - Redesign `/login` with large 56px inputs, "Show Password" toggle, and full-width "Log In" button.
