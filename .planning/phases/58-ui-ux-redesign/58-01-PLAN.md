### Task 2: Strict Light-Mode Sanitization (`UI-LIGHT-01`)
- **Target Files:**
  - `src/app/layout.tsx`
  - `src/app/globals.css`
  - `tailwind.config.ts` (or `tailwind.config.js`)
  - All components under `src/components/` and `src/app/`
- **Actions:**
  - Force `<html className="light" style={{ colorScheme: 'light' }}>` at root layout.
  - Remove any theme provider or dark mode toggles.
  - Search and replace all `dark:` utility classes with high-contrast light mode styling:
    - Pure white cards: `bg-white`
    - App background: `bg-slate-50` / `#F8FAFC`
    - Text: `text-slate-900` / `#0F172A`
    - Borders: `border-slate-200`
  - Confirm sunlight contrast compliance.
